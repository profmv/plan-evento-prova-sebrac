Tempo Restante: 20:00

Desafio dos 20 Minutos: Inversão Binária de Palavra (NOT na Fita)

Alan Turing concebeu o modelo de autômato universal que opera sobre uma fita. Nesta simulação, seu cabeçote deve percorrer a fita inicial 1 0 1 1 0 1, inverter cada bit (0 vira 1, e 1 vira 0) e parar no estado de aceitação HALT.

Estado Atual do Autômato: q0 (Leitura/Inversão) | Passos: 0

FITA DE MEMÓRIA (CABEÇOTE DESTACADO EM AMARELO)

Tabela de Transição de Estados (Programa da Máquina):

• (q0, '1') -> escreve '0', move DIREITA, vai para q0

• (q0, '0') -> escreve '1', move DIREITA, vai para q0

• (q0, ' ') -> move ESQUERDA, vai para q_halt (FIM DA FITA / SUCESSO)
